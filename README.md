## Deskripsi Proyek

Aplikasi REST API Perpustakaan yang dibuat menggunakan PHP, MySQL, dan JavaScript. Aplikasi ini digunakan untuk mengelola data buku dan kategori perpustakaan.

## Fitur

- Menampilkan daftar dan detail buku.
- Menambah, mengubah, dan menghapus data buku.
- Mengelola data kategori.
- Menampilkan dashboard total buku dan kategori.
- Menampilkan 5 buku terbaru.
- Integrasi frontend dengan REST API.
- Penerapan CORS, PSR-4, dan konsep SOLID.

## Teknologi

- PHP 8
- MySQL
- Composer
- JavaScript
- HTML dan CSS
- Tailwind CSS

## Cara Menjalankan Proyek

### 1. Backend

Buka terminal pada folder utama proyek, kemudian jalankan:

```bash
php -S 127.0.0.1:8000 -t public public/index.php
```

Backend berjalan di:

`http://localhost:8000`

### 2. Frontend

Buka terminal kedua:

```bash
cd frontend-perpustakaan
php -S localhost:3000
```

Buka aplikasi melalui:

`http://localhost:3000`
